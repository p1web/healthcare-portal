Password best practices

  • Use a unique password you don't reuse anywhere else.
  • Mix upper and lower case, numbers and symbols.
  • Avoid personal info like names, birthdays or phone numbers.
  • Consider a password manager to generate and store strong passwords.
  • Change your password if you suspect it has been shared.
